## 🎬 L'Adathèque

Une petite médiathèque veut cataloguer ses films. Deux tables suffisent : les genres, et les films qui appartiennent chacun à un genre.

À la fin de la semaine, l'application comprendra :
    - une base de données peuplée
    - une API REST documentée
    - une page web qui affiche, filtre et ajoute des films


Stack technique : 
    - Node.js / Express — serveur et routes de l'API
    - PostgreSQL (driver pg, sans ORM) — base de données
    - React — interface web (affichage, filtrage, ajout)
